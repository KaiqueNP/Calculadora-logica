# 🧠 Calculadora Lógica

Uma calculadora de lógica proposicional desenvolvida para facilitar o entendimento e a prática de operações lógicas básicas. Este projeto permite realizar operações como negação, conjunção, disjunção, condicional e bicondicional entre proposições lógicas.

## 🔧 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)

## ⚙️ Funcionalidades

- Interface interativa para inserção de proposições lógicas.
- Suporte às operações:
  - **~** : Negação
  - **∧** : Conjunção
  - **∨** : Disjunção
  - **→** : Condicional
  - **↔** : Bicondicional
- Exibição do resultado da operação lógica selecionada.
- Histórico das operações realizadas durante a sessão.

## 🚀 Como Utilizar

1. Clone o repositório:
   ```bash
   git clone https://github.com/kaiquenp/calculadora-logica.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd calculadora-logica
   ```
3. Abra o arquivo `index.html` em seu navegador preferido.
